# IdeaGitTool Desktop 0.4.1

本次交付第一阶段：签出增强、Reset 四种模式、本地修改备份恢复和 Reflog。

- 提交右键可签出、从提交创建分支或重置当前分支；工具栏支持输入标签和提交 SHA。
- 签出先尝试携带本地修改。覆盖受阻时显示文件列表，可临时保存后签出，或明确确认后强制签出。
- 远程签出显示已有本地分支关系，也可新建跟踪分支；其他 worktree 占用分支时显示目录并提供打开入口。
- Reset 默认 Mixed，支持 Soft、Mixed、Hard、Keep。预览显示当前分支、起点、目标、文件差异和将离开的提交。Hard 显示覆盖范围和可能覆盖的未跟踪路径，可先备份本地改动。
- 操作记录保存在仓库 Git 目录，记录原 HEAD、阶段、失败原因和备份 Stash SHA。签出后恢复修改时尝试还原暂存布局；恢复受阻作为独立阶段显示，备份继续保留。
- 操作恢复与 Reflog 可从原 HEAD 或历史提交创建恢复分支。应用重启后核对中断记录，不会自动重复执行恢复。
- 现有 Rebase 暂停信息显示进度、当前提交和 Git 能识别的暂停原因。高级 Rebase、`--onto` 和交互式提交整理留待第二、第三阶段。

`release/` 同步便携 EXE、安装包、便携 ZIP 和 SHA-256 清单。版本从 0.4.0 更新至 0.4.1。
