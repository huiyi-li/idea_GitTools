# IdeaGitTool 0.4.5

本次更新强化差异对比与三栏查看器的轻量编辑体验，升级独立 Patch 级 Shelf 与项目更新闭环，并新增高级历史检视与多仓库同步分支控制。

## 多仓库工作区

- 多仓库工具新增“跨仓库同步分支”管理，可查看各仓库分支状态与共有分支，并批量执行同步切换、新建或删除已合并分支。
- 多仓库聚合日志新增仓库色条标识、跨仓库搜索与分支筛选，支持一键导入工作区全部仓库及跳转定位至主窗口。
- 自动忽略常见构建与依赖目录的文件监听，提升工作区日常刷新响应速度。

## 提交与本地更改

- 双栏 Diff 与三栏提交查看器的工作区视图新增轻量编辑开关，支持在对比界面直接微调代码、按 Ctrl+S 保存修改或一键还原，历史提交栏保持只读。
- 预览与编辑模式均支持光标定位、文本选区、当前行高亮、光标行列状态显示与行号快速跳转，从预览切换到编辑时自动保留当前光标位置。
- 差异视图新增多语言语法高亮、行内字级差异高亮，以及 F7 / Shift+F7 差异块快捷导航。
- 新增独立于 Git Stash 栈的 Patch 级 Shelf 管理，支持按单文件或多文件局部 Shelve / Unshelve、未跟踪文件保存、回收站查看与一键还原，以及重命名和差异预览。
- 支持将 Shelf 或本地工作区更改导出为 `.patch` 文件，并支持导入或直接应用外部 `.patch / .diff` 文件。
- 变更列表与分支栏新增“按目录分组”折叠视图，并提供外部编辑器打开与系统资源管理器定位文件入口；提交说明本地规则生成按钮更名为“生成变更摘要”。

## 日志与提交图

- 提交图升级支持长边折叠与点击跳转、HEAD 标识与引用标签区分，并支持键盘翻页与父子提交导航。
- 新增历史提交变更的拆分与剔除操作，可在不影响工作区其他未提交更改的前提下，将提交中勾选的文件拆分为独立提交或直接剔除。
- 文件历史窗口新增代码选区演变历史查询及按提交版本浏览完整仓库文件树。

## 仓库工具

- 新增更新项目快捷键（Ctrl+T），拉取更新前自动备份本地历史并可选自动 Shelve / Stash 脏工作区，支持快进、变基或合并拉取，完成后自动恢复本地修改并在冲突时打开三栏合并器。
- 推送被拒绝时提供一键“拉取并重新推送”快捷操作（支持 Rebase 与 Merge 模式）。
