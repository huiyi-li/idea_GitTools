# IdeaGitTool 0.4.8

本次更新全界面新增自适应字符编码支持，完整兼容 GB2312、GBK、GB18030、UTF-16 等常见编码的查看、差异对比、冲突合并与编辑保存。

## 多仓库工作区

- 保持多标签多仓库工作台与持久化标签状态，各仓库的差异查看、三栏检视与合并界面均可独立识别与切换文件编码。

## 提交与本地更改

- 差异预览与轻量编辑支持自动识别 GB2312、GBK、GB18030、UTF-8 BOM、UTF-16LE/BE、Big5、Shift_JIS 等编码，并在保存时保留原文件编码格式。
- 差异视图、三栏查看器与合并管理器顶部新增编码选择下拉框，支持直观查看当前识别编码并手动切换编码重读或转换保存；若包含原编码无法表示的字符会给出明确提示。

## 日志与提交图

- 提交历史差异对比、三栏提交检视、行内 Blame 与 Local History 本地历史快照全面支持非 UTF-8 编码文件的正常文本读取与无损恢复。
