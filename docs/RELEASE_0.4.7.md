# IdeaGitTool 0.4.7

本次更新升级为持久化多标签多仓库工作台，支持同时管理多个不同路径的 Git 仓库并按需关闭与记忆标签状态，同时完善差异编辑、提交图与设置界面的交互体验。

## 多仓库工作区

- 新增多仓库标签栏，支持同时打开多个不同目录下的独立 Git 仓库，并实时展示每个标签的当前分支、变更数与冲突状态。
- 支持按需关闭对应仓库标签（单标签关闭按钮、鼠标中键、`Ctrl+W` 及右键菜单关闭当前 / 关闭其他 / 关闭右侧 / 关闭全部标签），并支持拖拽调整标签顺序与 `Ctrl+Tab` / `Ctrl+1~9` 快速切换。
- 退出并重启应用后自动恢复已打开的仓库标签列表、排序与激活标签，不会重置回旧工作区；同名跨目录仓库标签自动附加路径区分。
- 命令面板（`Ctrl+K`）与跨仓同步弹窗自动联动当前已打开的全部仓库标签，并支持在标签下拉菜单中一键重开最近关闭的仓库。

## 提交与本地更改

- 轻量工作区差异编辑在后台刷新或保存异常时继续保留未保存草稿，支持显式放弃与同步滚动偏好记忆。
- 行内 Blame 信息随工作区文件变更同步更新，避免混入暂存区旧内容。

## 日志与提交图

- 提交图上的 Fixup 交互式 Rebase 计划完整包含目标提交，便于直接整理连续历史记录。
- 提交记录右键菜单自动贴合窗口边界显示，避免在屏幕边缘被遮挡。

## 仓库工具

- 设置中心顶栏搜索框布局对齐优化，长窗口与窄屏下检索设置项更加清晰。
