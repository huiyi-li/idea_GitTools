# IdeaGitTool v0.4.2

本次发布汇总了自 v0.4.0 以来的更新，包含 v0.4.1 的签出、Reset 和操作恢复，以及 v0.4.2 的 GitHub / GitLab 登录、托管仓库管理和文件查看改进。

## GitHub / GitLab

- 新增多账户管理，支持 GitHub、GitLab、自建 GitLab 和 GitHub Enterprise 地址。
- 支持系统浏览器授权登录，也可继续使用访问令牌。公开 Client ID 按平台和服务器保存，账户凭据保存在系统凭据库。
- 网页登录支持取消、超时提示、拒绝授权处理和重新打开浏览器；到期的 OAuth 凭据自动续期。
- 支持托管仓库分页浏览、筛选、按路径打开，以及 SSH / HTTPS 克隆和本地目录关联。SSH 克隆可指定 Host 别名。
- 新增 PR / MR 列表、状态筛选、详情、提交、CI 状态和远程文件 diff；支持创建草稿、发布普通评论、关闭及重新打开请求。

## 签出、Reset 与恢复

- 支持签出提交、标签和 SHA，也可从指定提交创建分支。
- 切换分支时先尝试携带本地修改。遇到覆盖冲突后，列出受影响文件，可选择临时保存修改后签出，或明确确认后强制签出。
- 远程分支签出显示已有本地分支的对应关系，可选择现有分支或创建跟踪分支。分支被其他 worktree 占用时，显示目录并提供打开入口。
- 提交菜单新增“重置当前分支到此提交…”，默认使用 Mixed，支持四种模式。

| 模式 | 行为 |
| --- | --- |
| Soft | 移动分支指针，保留暂存区和工作区内容。 |
| Mixed | 移动分支指针，按目标提交重建暂存区，保留工作区内容。 |
| Hard | 移动分支指针，用目标提交覆盖暂存区和工作区。 |
| Keep | 更新到目标提交，遇到会覆盖本地修改的路径时终止。 |

- Reset 预览显示当前分支、起点、目标、将离开的提交和文件影响。Hard 额外显示覆盖范围，可选择先备份本地修改。
- 保存原 HEAD、操作阶段、失败原因和关联的 Stash。应用重启后可查看中断操作；恢复修改时尝试还原暂存布局，恢复冲突作为独立阶段显示，备份继续保留。
- 新增 Reflog 入口，可从原 HEAD 或历史提交创建恢复分支。
- 改进 Rebase 暂停信息，显示进度、当前提交和 Git 能识别的暂停原因。

## 提交与文件查看

- 日志页默认展示提交和变更文件列表，内嵌 diff 预览可按需开启并记住设置。
- 双击文件或按 Enter 打开只读三栏查看器，同时查看“修改前｜修改后｜当前工作区”。
- 支持切换“本次提交”和“后续变化”比较范围、变化导航、同步滚动、代码缩略图和栏宽调整。
- 刷新当前工作区内容时，历史两栏保持固定。文件后来再次重命名时，可关联当前文件。
- 分别展示文件不存在、空文件、二进制和无法加载等状态；首次提交及合并提交按对应父提交读取。

## 本地修改与大文件

- 已暂存文件查看 HEAD 与暂存区的差异，未暂存文件查看暂存区与工作区的差异。
- 新增逐文件和批量放弃修改。放弃未暂存更改时保留已有暂存内容；放弃全部更改前列出将恢复和删除的路径。
- 执行前重新校验文件和暂存区。预览过期时可重新获取，执行失败时尝试恢复操作前的文件，并在恢复受阻时显示备份目录。
- 本地 diff、提交三栏查看器和合并管理器支持按需加载大文件，每个版本最多 10 MiB、200,000 行。
- 大文件采用行级比较、纯文本编辑器和可见区域高亮；大文件合并支持保存进度、恢复草稿和完成暂存。
- 改进后台差异计算的超时、取消和过期结果处理，限制历史文件缓存。
- 文件类型判断遵循 `.gitattributes`，改进 EXE、DLL、LIB、OBJ 等二进制文件识别。

## 使用说明

网页登录首次使用需要注册自己的 OAuth 应用，并填写公开 Client ID。当前未内置统一的 OAuth 应用身份。

- **GitHub**：注册 OAuth App 并启用 **Enable Device Flow**，授权时在浏览器中输入应用显示的验证码。
- **GitLab**：注册 Application，取消 **Confidential**，选择 `api`、`read_user`，Redirect URI 填写 `http://127.0.0.1:34171/oauth/callback`。自建实例需在对应服务器注册。

当前已使用模拟授权服务器验证网页登录流程，真实账户授权需完成上述配置后验证。克隆操作继续使用系统 Git 的 SSH 或 HTTPS 凭据。

高级 Rebase、`--onto` 和交互式提交整理尚未包含在本次发布中。

## 下载与运行

本次提供 Windows x64 版本，运行需要系统 Git 2.43 或更高版本，以及 WebView2。

- `IdeaGitTool.exe`：直接运行。
- `IdeaGitTool-setup.exe`：安装包。
- `IdeaGitTool_0.4.2_windows-x64.zip`：包含程序和许可证的便携包。
- `release-manifest.json`：文件大小和 SHA-256 校验清单。

发布验证通过 100 项 Rust 测试、83 项界面测试、TypeScript 类型检查和生产构建。EXE 文件版本为 `0.4.2.0`，便携 ZIP 完整性及产物 SHA-256 校验通过。
