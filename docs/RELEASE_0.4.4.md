# IdeaGitTool 0.4.4

本次更新增加多仓库工作区、提交与历史工具，以及更完整的 Git 操作入口。

## 多仓库工作区

- 打开文件夹后，常驻标签显示各仓库的分支、变更数和冲突状态；可搜索并切换仓库。
- 每个仓库独立管理提交草稿、暂存区、文件选择和 Diff；提交页显示目标仓库路径。
- 新增多仓库远程同步与跨仓库提交记录查看，仓库历史操作保持单仓库目标。

## 提交与本地更改

- 新增 Shelf、Changelist 和文件本地历史快照；可查看并恢复历史内容。
- 新增本地规则生成提交说明、提交说明历史，以及提交后 Push 入口。
- 支持从文件或提交导出补丁，并复制路径、提交引用和相关信息。

## 日志与提交图

- 可从提交图发起 Cherry-pick、Revert、交互式 Rebase，并创建标签或编辑历史提交。
- 日志新增第一父提交筛选，以及按代码内容搜索提交；支持字面文本和新增／删除行正则。
- 文件差异可选显示行内 Blame，分支可收藏并显示与 upstream 的领先／落后数量。

## 仓库工具

- 新增 Git 诊断、Bisect、Submodule 状态与更新，以及 Git LFS 文件状态。
- Remote Fetch 支持清理失效引用；Push 提供目标分支及其他高级选项。
