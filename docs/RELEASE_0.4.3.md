# IdeaGitTool 0.4.3

本次更新补齐独立 URL 克隆、分支和远程管理、交互式 Rebase、文件历史与 PR / MR 审查，并修复合并进度恢复和 Stash 操作中的问题。新增应用内更新，可从 GitHub Releases 下载签名安装包并安装重启。

## 仓库与分支

- 支持直接输入 SSH、HTTPS 或 HTTP 地址克隆仓库，显示进度、认证提示和失败原因，可取消任务，完成后直接打开。Git 传输沿用系统 SSH 配置和 Git 凭据，支持 SSH Host 别名。
- 新增 Remote 管理，可添加、修改和删除远程，配置 Fetch / Push 地址。首次 Push 可选择远程并建立 upstream。
- 分支菜单支持从选中分支创建分支、签出、重命名和删除。快速合并提供普通合并、禁止快进、仅快进和 Squash 入口，也可发起 Rebase。
- 支持创建、删除和推送标签，删除远程引用时核对远程状态。
- 新增 Worktree 管理，可创建、打开、锁定、解锁和移除工作树，显示分支占用及本地修改情况。
- 新增忽略规则与停止跟踪入口，停止跟踪时保留磁盘文件，执行前核对工作区和暂存区状态。

## 提交与历史

- 支持按变化块或选中行暂存、取消暂存和放弃修改，保留同一文件中的其他更改。大文件变化块按可见区域渲染。
- 支持 Amend 最近提交，修改提交说明和暂存内容。
- 新增交互式 Rebase，可调整提交顺序，编辑说明、合并提交、Fixup、删除提交或暂停编辑，并支持继续、跳过和中止。
- 新增文件历史与 Blame，可查看来源提交、作者及对应差异，历史记录支持跟随重命名。
- 日志新增作者、日期、路径和提交范围等组合筛选，可保存仓库专属筛选预设。

## 合并与 Stash

- 合并窗口提供整文件采用当前侧或传入侧的快捷操作，覆盖手工编辑前显示确认，支持预览和撤销。
- 修复保存合并进度后重新打开窗口又显示未处理的问题，保留结果内容及冲突块的处理状态。
- 修复选择一侧解决冲突时，父目录已删除导致文件无法恢复的问题。
- 改进 Stash 的弹出、应用并保留、删除、清空及差异查看，支持选中文件恢复、还原暂存布局，以及从储藏基准创建恢复分支。
- Stash 恢复发生冲突时保留储藏并打开合并管理器，列表变化后重新核对选择，避免操作到其他条目。
- 修复远程分支操作后的列表刷新，以及部分选中内容清理问题。

## 平台协作与更新

- GitHub / GitLab 的 PR / MR 增加行内讨论、审批、远程合并和检出分支入口，操作前核对选中的请求与提交。
- 底部版本按钮可查看新版本和发布说明，显示下载进度，完成签名校验后安装并重启。
- 默认启动时检查更新，可关闭自动检查，也可开启发现新版本后自动下载。安装前保存当前仓库和提交信息草稿，Git 操作执行期间等待操作完成。
- 更新安装沿用 NSIS 安装流程，支持需要管理员授权的安装目录。网络、清单和签名校验失败时提供错误提示、重试和 GitHub 发布页入口。

## 下载与升级

本次提供 Windows x64 构建。

- `IdeaGitTool-setup.exe` 为安装包。
- `IdeaGitTool_0.4.3_windows-x64.zip` 为包含程序和许可证的便携包。
- `IdeaGitTool.exe` 可直接运行。
- `IdeaGitTool-setup.exe.sig` 和 `latest.json` 用于应用内签名更新，`release-manifest.json` 提供程序及更新文件的 SHA-256 校验值。

首次启用应用内更新时，先手动安装包含更新功能的版本。后续正式版本发布到 GitHub Releases 后，可从应用内检查并安装。便携用户可继续从发布页下载 ZIP。
