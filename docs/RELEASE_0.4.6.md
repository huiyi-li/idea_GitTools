# IdeaGitTool 0.4.6

本次更新带来全新现代化双栏设置中心、全局命令面板（Ctrl+K）与全面升级的界面交互体验。

## 多仓库工作区

- 新增全局命令面板（Ctrl+K），支持模糊搜索并键盘直达任意 Git 工具、分支切换、最近仓库切换与设置项。
- 顶部“仓库工具”菜单按功能域清晰分组，多仓库同步与分支管理弹窗升级为现代分段标签导航。

## 提交与本地更改

- Shelf 管理新增可点击卡片快捷列表，配合现代分段标签栏提升多条目切换与差异预览效率。
- 编辑器字号、行高、代码缩略图、Inline Blame、同步滚动及字级差异高亮等偏好均可在设置中心统一配置并实时生效。

## 日志与提交图

- 提交右键菜单新增直接浏览该提交时刻完整仓库文件树的快捷入口。
- 文件历史窗口升级为现代分段标签栏，方便在文件历史、Blame、代码选区历史与提交文件树间快速切换。

## 仓库工具

- 新增现代化双栏设置中心（Ctrl+, 或点击顶栏齿轮打开），支持跨分类关键字搜索与一键恢复默认设置。
- 设置中心新增主题模式切换（深色 / 浅色 / 跟随系统）、界面紧凑度选择、外部编辑器命令自定义、Update Project (Ctrl+T) 默认整合与自动暂存策略，以及全局快捷键速查表。
- 操作完成通知升级为右下角自动消失的浮动提示，弹窗遮罩新增毛玻璃视觉层次。
